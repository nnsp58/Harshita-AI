# 15 Roadmap

## Immediate Priorities (Version 1.0)
- Core Infrastructure (Kernel, Context Bus, Event Bus, AI Service Bus).
- Monorepo structural migration (`apps/web`, `packages/kernel`).
- Plugin SDK standardization.

## Version 2.0 (Ecosystem Expansion)
- **Plugin Marketplace**: Dynamic installation of third-party Agents.
- **Harshita Desktop**: Electron wrapper utilizing the shared OS kernel.
- **Harshita Developer CLI**: `harshita plugin create`, `harshita doctor`.

## Version 3.0 (Enterprise)
- Advanced Workflow Automation (B2B).
- Cloud storage providers natively integrated with `StorageProvider` abstraction.

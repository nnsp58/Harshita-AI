# 05 Workspace System

## Overview
Workspaces are the UI containers (Plugins) for the output generated by Agents. They are fully decoupled from the Core OS.

## Workspace SDK
Every Workspace must implement the `WorkspaceSDK` which enforces the standard `AIPlugin` lifecycle.
Mandatory behaviors:
- Support for `suspend()` and `resume()` (Smart Switching).
- Support for `autosave()` (Background persistence).
- Support for `export()` (PDF, JPG, Text).

## Abstraction
Workspaces never directly update global state. They emit events (`DOCUMENT_MODIFIED`) to the Event Bus.
